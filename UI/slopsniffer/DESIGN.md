# SlopSniffer candidate system

These are alternatives for review, not a selected production identity.

## Shared system
Operate mode: people inspect a finding quickly, then return to the host page. Keep one main action in the popup. Keep page annotations small and show explanations on selection. Activity opens separately; settings are secondary.

User palette: Ghost White #FEF9FF, Powder Petal #F2DFD7, Thistle #D4C1EC, Soft Periwinkle #9F9FED, Medium Slate Blue #736CED. Added text tokens: ink #292338, muted #686173, accessible action purple #554BAF, separators #E5DFE9. Inactive surfaces remain near-white; brighter supplied colours carry fills and highlights instead of small text.

System UI typography, 18px popup finding, 12–14px supporting content, 20px interior spacing. Compact on/off control, one Compare reviews button, quiet Activity and Settings footer. Original oval snout with two nostrils; no game character assets. Artificer influence is limited to the supplied colour palette.

## Alternatives
- Snout-o: peach snout replaces the o in Slop, mixed-weight wordmark, white surface and purple action.
- Pocket pig: standalone snout toolbar mark, lavender header, peach action.
- Underline: lowercase wordmark, outline snout, minimal filled surfaces, underlined action.

## Evidence behaviour
Every verdict and count is a sample. Distinguish repeated wording from bots or AI authorship. Actual comment clusters, exact passages, and platform extraction require backend work. Do not turn preview text into production findings. The reviews preserve individual authorship boundaries.

## Validation and provenance
Browser interactions passed for direction selection, compare, passage explanation, Escape, dismissal, representative match, pause/resume, and sample activity. No horizontal overflow at 960, 390, or 320px; no JavaScript page errors. Desktop and mobile screenshots inspected. Independent finish review: ship for presenting design candidates only, not production integration or detector behaviour.

All PNG files under screenshots/ are browser captures of the authored HTML/CSS in this directory. `snout.svg` is original vector geometry. No generated raster art or external game artwork is included.
