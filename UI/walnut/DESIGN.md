# Walnut screen family

User-selected world: warm paper #FAF7F1, ink #29231F, secondary #63564B, separators #DED5C8, soft #EEE8DE, walnut #8C5C38, readable action #744E32, highlight fill #F3EADB. Serif branding and report title, system UI controls, host website typography preserved.

Classic keeps compact familiar controls and quiet serif branding. Compact uses a sans brand, smaller gaps, and denser extension-owned surfaces. Casebook keeps white paper and applies a dark walnut masthead and stronger square evidence boundaries. None paints the host website brown. The original hat-and-pipe mark is the single expressive brand element.

Nine screens map the complete end-user surface set. The first four map Toby's reference pages directly. Articles show whole-paragraph model flags separately from exact copied passages. An explanation is closed initially and opens on selection. Popup is anchored to a toolbar scene. Dashboard is a separate page. My sites and status/error cases are represented. Shopping, Reddit, and YouTube are proposed per-item text-similarity interfaces only. Image/video models are not represented as working.

Rendering was checked for 27 screen/style combinations and nine screens at 390px/320px. Meaningful browser checks cover evidence open/close/Escape, search restore/hide, article highlight visibility, report ranges/selected bars, sample site removal, popup navigation and off state. All passed with no JavaScript page errors. PNG files are browser captures of authored HTML/CSS, not image-generated screenshots. Overview/alternatives are browser-rendered contact sheets of those captures.

Impeccable's heuristic scan was run. Its cream/font and sample marketing-copy warnings are intentional given the selected palette, authentic host typography and illustrative AI-like article. Static CSS analysis also conflates transparent play-icon triangles with thick card borders; those triangles are video-placeholder marks, not UI ornament. Mechanical issues found during validation (toggle pointer handling and review heading levels) were corrected. The scan is not an accessibility certification or detector evaluation.
