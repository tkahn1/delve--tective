# HACK2026

Unslop: a local Chrome extension for search and article content signals.

## UI review

Arnav's UI previews and Quiet dashboard are in [UI/](UI/README.md). From the repository root, run `python -m http.server 8080` and open **http://localhost:8080/UI/**.

Previews use clearly labeled sample data. They are separate from the installed extension. See [UI/TESTING.md](UI/TESTING.md) for real-site testing, model setup, and why Amazon/Reddit comments are not supported yet.
