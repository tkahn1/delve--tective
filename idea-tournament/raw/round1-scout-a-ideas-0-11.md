# Round 1: scout a ideas 0 11

Verbatim final report from this subagent.

Prior-art scout, ideas 0-11. All findings come from this session's searches. I did not open GitHub or Devpost pages directly, and some Devpost URLs are not given because search snippets did not return them.

**#0 Verified AI Code** — Verdict: EXISTS. Closest: Crosscheck Claude Code plugin (marketplace repo nicholls-inc/claude-code-marketplace; listing https://skillselion.com/skills/nicholls-inc/claude-code-marketplace/crosscheck). It checks Claude's code with Dafny and compiles to Python or Go. Also lemmafit (midspiral/lemmafit, Dafny with Claude Code) and Emergence's VCG verified coding agent (https://www.emergence.ai/blog/vcg-a-high-performance-verified-coding-agent-for-python). Claims: Clover (arXiv 2310.17807, SAIV 2024) CONFIRMED. Red flag: plugin is small (about 5 stars), but the idea is already shipped.

**#1 Vault** — Verdict: DIFFERENT. Closest: Vandal (https://devpost.com/software/vandal). A Claude finance agent with a deterministic checker and counterexample-guided policy synthesis, with no Dafny. Crosscheck (see #0) covers the English-to-Dafny loop generically. I found nothing that replays Dafny counterexamples as Nessie transactions. Claims: Clover CONFIRMED. A Dafny counterexample is not guaranteed on failure. Red flag: Dafny does give counterexamples, but they are often not concrete or are missing, so "replay the counterexample" may need a bounded search fallback.

**#2 Monkey's Paw** — Verdict: NOVEL. Closest: holey (https://github.com/namin/holey) is an SMT-plus-LLM puzzle solver. No wish or genie game with a solver found. Claims: z3-solver npm package ships WASM for browser and Node, CONFIRMED. Red flag: the default build needs SharedArrayBuffer, so the page needs COOP/COEP headers. A single-threaded build (`z3-solver/singlethread`) appeared in a Z3 commit, but I found no release notice. Funny output depends on the LLM, not Z3.

**#3 Who Can See This?** — Verdict: EXISTS (NL-to-Cedar with verifier loop). Closest: AutoCedar, arXiv 2607.03656 (https://arxiv.org/pdf/2607.03656). It turns natural-language access-control requirements into Cedar with verifier-guided repair, and reports 221 CedarBench tasks converging. Claims: AutoCedar CONFIRMED (posted July 2026, Stevens Institute of Technology). cedar-policy-symcc is real (https://docs.rs/cedar-policy-symcc), version 0.1.3 on Dec 2025, with check_never_errors and check_always_allows. Red flag: it needs a cvc5 binary at runtime, and cvc5 is the only supported solver. Windows build risk stands.

**#4 Tripwire** — Verdict: EXISTS (as a demo). Closest: IntentBinding (https://hackquest.io/en/projects/IntentBinding). CaMeL-style planner/quarantine split with a guard toggle, baseline drained vs blocked side by side. Claims: CaMeL (arXiv 2503.18813) CONFIRMED. Public code at https://github.com/google-research/camel-prompt-injection. The paper's abstract says 77% of AgentDojo tasks solved with provable security (a secondary source said 67%). Red flag: Claira (https://devpost.com/software/claira) noted that newer models often refuse the injections, so the baseline may not fall for the attack.

**#5 Ghost Imports** — Verdict: EXISTS. Closest: PkgGuard (VS Code extension, checks PyPI and npm imports live; found on a GitHub mirror, no clean URL). Also Phantom Guard, slopcheck (https://pypi.org/project/slopcheck/), ghostpkg (https://pypi.org/project/ghostpkg/), slopguard-cli. Claims: Spracklen et al. USENIX Security 2025 CONFIRMED (https://www.usenix.org/conference/usenixsecurity25/presentation/spracklen). Rates found: at least 5.2% for commercial models and 21.7% for open-source models, 576,000 samples. Red flag: the market is crowded, so the "scan HackUMass repos" angle is the only twist.

**#6 Blacklight** — Verdict: EXISTS. Closest: Embrace The Red's ASCII Smuggler, and many clones: Unsmuggle (https://this.is-a.dev/projects/unsmuggle), PromptShield on npm (https://promptshield.js.org/docs/overview/), OpenReplay invisible character cleaner, and a Hidden Character Detector VS Code extension. Claims: sources conflict on whether Claude follows Unicode tag instructions. An Embrace The Red post from Feb 2026 reported consistent invisible-Unicode detection and refusals from Claude Code. The "Reverse CAPTCHA" study said Sonnet 4 followed hidden instructions 71.2% of the time with tools enabled. Red flag: the chatbot may not obey the hidden text live. Microsoft notes the England, Scotland and Wales flag emoji use tag characters, so a naive filter breaks them.

**#7 Glance** — Verdict: DIFFERENT. Closest: Google Look to Speak (https://experiments.withgoogle.com/looktospeak), a fixed phrase list, Android only. SpeakFaster (Google Research blog https://research.google/blog/speakfaster-revolutionizing-communication-for-people-with-severe-motor-impairments/, Nature Communications) uses an LLM to expand initials into phrases for gaze typists, and reports text-entry rates 29-60% faster for two ALS users. I found no WebGazer-plus-LLM project. Claims: WebGazer works but is unmaintained. The README says "fully functional" as of 24 Feb 2026 but updates are no longer guaranteed. Official browser list includes Chrome, Edge, Firefox, Opera and Safari. Red flag: GPLv3 license, and I found no published accuracy numbers.

**#8 Proof of Typing** — Verdict: DIFFERENT. Closest: Kundu et al., "Keystroke Dynamics Against Academic Dishonesty in the Age of LLMs" (https://arxiv.org/html/2406.15335v1), a TypeNet-based classifier. Claims: arXiv 2406.15335 CONFIRMED. arXiv 2601.17280 CONFIRMED: Condrey, Jan 2026, claims a copy-type attack evades five classifiers at 99.8% or more and that timing-only detection is non-identifiable. Red flag: this is the exact attack the demo shows (retyping). A Korean-dataset paper, arXiv 2507.22956, separates transcribing from paraphrasing, so the demo may work only against naive retyping.

**#9 Tell** — Verdict: DIFFERENT. Closest: the Deepstack poker show uses webcam rPPG to display heart rates (https://www.pokernews.com/news/2026/09/deepstack-poker-heart-rate-monitoring-high-stakes-tension-52341.htm). Several Devpost webcam-pulse projects exist (e.g. https://devpost.com/software/sixth, https://devpost.com/software/cor). I found no bluffing party game. Claims: Verkruysse 2008 and Wang 2017 not checked by search, COULD NOT CONFIRM. Red flag: sources say webcam rPPG gives usable average heart rate but not precise short-window readings, and a bluff game needs moment-to-moment change.

**#10 Wand Duel** — Verdict: EXISTS. Closest: Arcania (https://github.com/math-pixel/arcania), where you scan a QR and use your phone as a magic wand against a desktop game. Also Spell Duel (https://skich.app/games/spell-duel), phones pair and spells are air-drawn patterns on the accelerometer. Phone Party (Devpost) uses phone motion for swing and jab. Claims: no paper claims. Red flag: iOS requires a motion-permission tap after a user gesture. I found nothing on gesture recognition for unseen users.

**#11 Feel the Graph** — Verdict: EXISTS. Closest: ChartA11y (iOS app, direct-touch mode with pitch tones and vibration while the finger crosses data points). Also TactualPlot (IEEE VIS 2023, https://virtual.ieeevis.org/year/2023/paper_v-full-1245.html), and a University of Maine spatial-audio touchscreen graph study (https://umaine.edu/vemi/?p=5449). Claims: Apple Audio Graphs not checked, COULD NOT CONFIRM. Red flag: navigator.vibrate is unsupported on iOS Safari through 26.3 (https://caniuse.com/vibration). Apple opposes the API. A workaround via `input type=checkbox switch` exists but is a hack. Android vibration is on/off only.
