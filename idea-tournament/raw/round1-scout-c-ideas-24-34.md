**#24 Calm Race** — Verdict: DIFFERENT. Closest: Saskatchewan dissertation game "In the Same Boat" (https://harvest.usask.ca/bitstream/10388/13794/1/ROBINSON-DISSERTATION-2022.pdf), a two-player breathing game that uses webcam heart rate. Also Devpost Corisol (https://devpost.com/software/corisol) and Sixth (https://devpost.com/software/sixth), both webcam rPPG wellness tools and not games. No Devpost game with this exact shape was found. Claims: ME-rPPG paper arXiv 2504.01774 CONFIRMED. open-rppg is pip-installable with the ME-chunk and ME-flow models. Code is MIT; weights are labeled research-only. Red flag: none found beyond the weight licence. #9 Tell uses the same rPPG stack.

**#25 Mind Charades** — Verdict: DIFFERENT. Closest: Neuronpedia's word-association game (https://forum.effectivealtruism.org/posts/syEQKdmhNHbrBqtwe/neuronpedia-ai-safety-game) and the Taboo-model paper arXiv 2505.14352. Neither is a player-facing "make the neuron fire" game. Claims: Gemma Scope 2 CONFIRMED (https://huggingface.co/google/gemma-scope-2). It covers 270M, 1B, 4B, 12B and 27B, with SAELens as the library. The 1B repo page and its SAELens release ID were not found (the 27B-it example is `gemma-scope-2-27b-it-resid_post`, `layer_12_width_16k_l0_small`). Red flag: none found.

**#26 Was That Me?** — Verdict: DIFFERENT. Closest: AudioSeal's own demo and detector (https://pypi.org/project/audioseal/). No hackathon project found. Claims: AudioSeal, ICML 2024, CONFIRMED. It detects only watermarked audio. Chatterbox: NVIDIA lists about 2.3 GB VRAM for Turbo and about 3.5 GB for Multilingual in TTS-only mode (https://docs.nvidia.com/ace-for-games/chatterbox-tts/nvigi-chatterbox-model-card.html). Cloning needs 5-30 s of reference audio. Red flag: SERIOUS. One benchmark, SoK arXiv 2503.19176, measured AudioSeal over-the-air detection at about 0.07-5%. The table was garbled and I did not verify it against the PDF. The speaker-to-mic demo is likely to fail.

**#27 Did It Read Me?** — Verdict: DIFFERENT. Closest: Have I Been Trained is dataset search, not a membership test. No per-token heat-map membership tool was found. Claims: Min-K%++ (ICLR 2025) CONFIRMED. The repo is https://github.com/zjysteven/mink-plus-plus. It supports Pythia 2.8B, 6.9B and 12B. Red flag: CheckMIABench (arXiv 2606.17464) reports near-chance AUC (about 0.49-0.50) on Pythia models on its cleaned Pile split. The demo may not separate known from unknown text.

**#28 Shaky** — Verdict: DIFFERENT. Closest: UQLM, CVS Health (https://cvs-health.github.io/uqlm/latest/_notebooks/examples/long_text_qa_demo.html). It does claim-level semantic-entropy-style scoring as a library and has no UI. RELIC (arXiv 2311.16842) is a per-claim consistency interface. Claims: Farquhar et al., Nature 2024: not searched this session. Red flag: the reference code runs about $5-30 per run on OpenAI models. Closest code exists, so the novelty is only the wobble UI.
